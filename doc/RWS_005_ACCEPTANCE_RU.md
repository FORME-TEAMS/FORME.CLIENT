# RWS-005: оставшаяся игровая приёмка

Актуальный клиент: `FORME-TEAMS/FORME.CLIENT`; для проверки 25 ноября 2026
использована ветка `fix/macos-universal-vlc-plugins`. Серверный реестр требований и статус RWS-005 остаются каноническими.
Финансовое переключение отложено; голосового общения нет; поток региона сохраняется.

Проверки ниже **ещё не выполнены двумя графическими клиентами**. Предварительные
тесты исходников, успешная компиляция и серверные фикстуры не меняют этот статус.
Для каждого прогона фиксируются commit клиента и сервера, конфигурация регионов,
время, шаги, журналы без секретов и результат. Испытания выполняются в тестовой копии.

Серверный блок prepared close фиксирует circuit, presence, клиент и ревизию контекста
до помещения HTTP-запроса в очередь. Его автоматические проверки задерживают старую
операцию, обновляют circuit с той же SessionID и подтверждают отказ без закрытия нового
подключения. Повторы объединяются только внутри одного захваченного контекста.
Подтверждение `queued` означает допуск в очередь, а не удаление аватара.

Это локальная защита уже принятой операции. Глобальный порядок старых и новых запросов,
впервые прибывших после следующего create, и атомарная транзакция всех scene/UDP/engine
writers остаются серверной работой. Новый сетевой формат клиента этим блоком не вводится.

RWS-005 остаётся **in_progress**, RWS-006 — **pending**. Для закрытия этапа нужны
подтверждённые результаты открытых сценариев, а не только увеличение числа тестов.
Автоматическая установочная сборка этим документом не запускается.

проверки исходников и упаковки, без установочной сборки и без закрытия игровой приёмки.
