# Подключение клиента ForMe.World

Клиент работает с адресом служб входа ForMe.World, заданным при configure. Выбор произвольных сетей, сторонние регистрация, восстановление пароля и ссылки на внешние платёжные службы не предоставляют обхода этой политики.

Адрес задаётся командой `python3 scripts/forme_client.py configure --grid-url https://grid.example.org:8002/`, затем требуется повторная компиляция. Пример замените реальным адресом. Пароли и токены в URL запрещены.

Ссылки приложения используют `fmw://`. Права создания, роли, бейджи, доступ к серверным capability и финансовые разрешения определяются сервером. Локальная настройка клиента не является разрешением.

Для проверки используйте новый и ранее сохранённый профиль, вход/выход, профиль другого пользователя, переход A → B → A и отказ входа. Ответы старого региона или сессии не должны восстанавливать контекст.

Полная игровая приёмка остаётся открытой. Не заменяйте сетевые/серверные отказы статическими успешными экранами и не включайте голосовое общение ради совместимости.
