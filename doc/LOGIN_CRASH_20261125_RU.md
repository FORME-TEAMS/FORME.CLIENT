# Падение при входе: панель групп, 25 ноября 2026

Пользовательский журнал клиента заканчивается 25 ноября в 23:24:12 МСК
после `STATE_SEED_GRANTED_WAIT → STATE_SEED_CAP_GRANTED` и инициализации
сообщений. Отчёт macOS фиксирует `EXC_BAD_ACCESS / SIGSEGV` по адресу `0x160`
на главном потоке. Первые символизированные frames:

```text
LLButton::setClickedCallback(...)
LLPanelGroup::postBuild()
LLPanel::initPanelXML(...)
LLFloaterSidePanelContainer::getPanel(...)
idle_startup()
```

В `LLPanelGroup::postBuild` остался вызов
`mButtonCall->setClickedCallback(onBtnGroupCallClicked, this)` после удаления
голосовых контролов. Поле инициализировалось `nullptr` и нигде не получало
указатель на кнопку. Панель создаётся во время входа; открывать группы вручную
для воспроизведения не требуется. Это обращение точно соответствует стеку.

Удалены поле, callback, пустой `callGroup()` и связанные операции показа и
раскладки кнопки звонка. Текстовый `chatGroup()` продолжает вызывать
`LLGroupActions::startIM`. Остальной групповой интерфейс сохранён.

Журнал также выявил две отдельные ошибки UI:

- `emoji_recent_layout_panel` и `unread_messages_holder` находились прямо в
  обычной panel. Их тип зарегистрирован у layout_stack, поэтому factory
  отклоняла создание, а getChild создавал dummy controls. Добавлены корректные
  layout_stack-родители в затронутых скинах/локализациях, внутри прежнего
  скрытого legacy-контейнера; существующие имена и callbacks сохранены.
- WMap-размеры шрифтов были определены только в резервном XUI fonts.xml.
  LLFontGL сначала загружает install_dir/fonts. Размеры добавлены во все
  поставляемые font profiles; исправлен неверный атрибут `font_style` заголовка
  чата на поддерживаемый `font.style`.

## Проверка

`python3 scripts/forme_preflight.py` пройден полностью, включая проверки
поставки ресурсов, отсутствия VOICE, упаковки macOS/universal, UI, чата и групп.
Новый `tests/forme/check_login_startup_ui.py` — три успешные проверки. Он
подключён к preflight и проверяет удалённый call API, допустимость родителей
layout_panel и наличие WMap-размеров в реально загружаемых font profiles.

Отрицательные проверки: исходный group cpp/header из e00ca8b7 отклоняется новым
guard; исходные chat/font resources приводили к двум ошибкам нового теста.
Рабочие исходники при отрицательной проверке группы не заменялись.

Полная компиляция/линковка macOS и вход после исправления в этом Linux-стенде
не выполнялись. Для установки исправления нужна новая клиентская сборка:
успешная сборка e00ca8b7 с восстановленными avatar resources ещё содержит этот
отдельный дефект group UI. Предварительные проверки не закрывают graphical
приёмку RWS-005. Серверных ini/SQL изменений этот фикс не требует.
