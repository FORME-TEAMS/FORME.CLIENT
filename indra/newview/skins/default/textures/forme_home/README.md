# ForMe World home demo artwork

These are bundled, generated placeholder assets for the in-client home dashboard.

- `home_hero.jpg`: panoramic hero artwork with the ForMe avatar and neon waterfront city.
- `cards_atlas.jpg`: 3 × 3 atlas (402 × 225 px; each cell is 134 × 75 px) for the five feature cards, spring event, and two news thumbnails.

The named atlas clips are registered in `../textures.xml`. Keep the texture names stable when replacing the images so the XUI layout does not need to change.

All copy and dates shown with these images are demo content. Before release, replace the static artwork and demo copy with media and metadata supplied by the configured ForMe content sources. Do not treat these generated images or the displayed event/news details as live world content.
