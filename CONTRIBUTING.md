# Разработка ForMe.World

Рабочая основа — ветка `main` этого закрытого репозитория. Для задачи создавайте отдельную ветку и pull request. Самостоятельная публикация, изменение видимости репозитория и выпуск приложения не являются частью обычного изменения исходников.

В описании изменения указывайте проблему, итоговое поведение, проверку и известные ограничения. Для интерфейса прикладывайте изображения до и после; для сетевых изменений — воспроизводимый сценарий, включая смену региона и сессии.

Перед отправкой выполните `python3 scripts/forme_client.py check`. Для C++ изменений нужны проверки компиляции затронутых файлов и соответствующая полная сборка платформы. Нельзя отключать проверки ради зелёного статуса или выдавать предварительную проверку за готовое приложение.

Сохраняйте действующие лицензии и уведомления авторов. Не добавляйте пароли, ключи, локальные настройки входа, сертификаты, рабочие каталоги компиляции и скачанные пакеты. Права пользователя определяет сервер; клиент не должен назначать себе роли или разрешать создание контента обходным путём.

Голосовое общение не возвращается. Музыка и прямой поток региона сохраняются. Изменения финансовой подсистемы согласуются отдельной задачей.
