# ForMe.World

Клиент виртуального мира **ForMe.World** для общения, исследования регионов, работы с личным инвентарём и создания контента.

Это отдельный закрытый репозиторий команды ForMe.World. Основная ветка — `main`. Исходники, обсуждения и артефакты сборок доступны участникам с выданным доступом.

## Возможности

- Подключение к сети ForMe.World и переходы между регионами.
- Личный профиль, друзья, группы, уведомления и текстовые диалоги.
- Инвентарь, сохранённые образы и примерочная.
- Карта мира с опубликованными фотографиями регионов.
- Маркет, карточки товаров и интеграция с серверными службами.
- Инструменты создания для пользователей с правами, выданными сервером.
- Музыка и прямой медиапоток региона. Голосового общения нет.

[Полное руководство](doc/BUILD.md) описывает инструменты, получение исходников, настройку адреса сервера, компиляцию, запуск и диагностику.

| Система | Инструкция | Результат |

## Состояние разработки

Клиент находится в разработке. Контекст мира, региона и сессии защищён от применения старых ответов после перехода. Полная игровая приёмка двумя клиентами, сценарии вложений и скриптов, нагрузочные проверки и завершение RWS-005 ещё открыты. Наличие инструкции или успешных предварительных проверок не означает готовность всех платформ к выпуску.

Технический статус: [контекст мира и переходов](doc/forme-world-real-world.md), [интерфейс](doc/FORME_UI_REDESIGN_ROADMAP_RU.md), [работа без голосового общения](doc/FORME_NO_VOICE_RU.md).
